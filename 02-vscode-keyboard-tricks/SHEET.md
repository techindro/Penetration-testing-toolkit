# 💻 Module 02: VS Code Comprehensive Keyboard Shortcuts

Master list of keyboard shortcuts for Visual Studio Code to speed up editing, navigation, multi-cursor manipulation, and debugging.

---

## ⚡ 1. Daily Command & File Navigation

| Key Combination | Action (Simple Explanation) |
| :--- | :--- |
| `Ctrl + Shift + P` | Open Command Palette (Search any setting, command, or extension). |
| `Ctrl + P` | Quick File Open (Jump directly to any file in your project by typing its name). |
| `Ctrl + B` | Toggle the left file explorer sidebar on or off. |
| `Ctrl + ~` (Backtick) | Open or close the integrated terminal pane. |
| `Ctrl + Shift + F` | Global Search across all files in the entire project workspace. |
| `Ctrl + Shift + H` | Global Search and Replace across all files in the project. |
| `Ctrl + G` | Jump directly to a specific line number. |
| `Ctrl + Shift + O` | Jump to a specific symbol, function, or variable in current file. |

---

## ✏️ 2. Multi-Cursor & Line Editing Tricks

| Key Combination | Action (Simple Explanation) |
| :--- | :--- |
| `Alt + Click` | Insert additional cursors at clicked locations to edit multiple lines at once. |
| `Ctrl + D` | Select current word, press repeatedly to select next matching occurrences. |
| `Ctrl + Shift + L` | Select ALL occurrences of the current word in the file simultaneously. |
| `Alt + Up / Down` | Move current line or selected block up or down. |
| `Alt + Shift + Up / Down` | Duplicate current line or selection up or down. |
| `Ctrl + /` | Toggle line comment or uncomment for current selection. |
| `Shift + Alt + A` | Toggle block comment (`/* ... */`) for selection. |
| `Shift + Alt + F` | Format entire code document according to style guide. |
