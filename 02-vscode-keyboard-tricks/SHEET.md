# 💻 Module 02: VS Code Comprehensive Keyboard Shortcuts

Master list of keyboard shortcuts with practical usage examples for Visual Studio Code.

---

## ⚡ 1. Daily Navigation & Search Shortcuts

| Key Combination | Action (What it does) | Practical Usage Example |
| :--- | :--- | :--- |
| `Ctrl + Shift + P` | Open Command Palette. | Press `Ctrl+Shift+P`, type `Format Document` or `Git: Clone` to run commands. |
| `Ctrl + P` | Quick File Open. | Press `Ctrl+P`, type `server.js` or `index.html` to open the file immediately. |
| `Ctrl + B` | Toggle left sidebar. | Press `Ctrl+B` while coding to hide sidebar and maximize workspace screen space. |
| `Ctrl + ~` (Backtick) | Toggle integrated terminal. | Press `Ctrl+~` to pop open terminal, run `npm start`, then hide it again. |
| `Ctrl + Shift + F` | Global Search across project. | Press `Ctrl+Shift+F`, type `DATABASE_URL` to find where DB is configured across all files. |
| `Ctrl + G` | Jump to specific line. | Press `Ctrl+G`, type `145` to jump straight to line 145 mentioned in an error stacktrace. |

## ✏️ 2. Multi-Cursor & Editing Examples

| Key Combination | Action | Practical Usage Example |
| :--- | :--- | :--- |
| `Alt + Click` | Insert multiple cursors. | Click at the beginning of 5 lines to add `const ` to all 5 variables at once. |
| `Ctrl + D` | Select next matching word. | Highlight `user_id`, press `Ctrl+D` 4 times, type `userId` to rename all 4 variable instances. |
| `Ctrl + Shift + L` | Select ALL matching occurrences. | Highlight `oldFunctionName`, press `Ctrl+Shift+L`, type `newFunctionName` to rename everywhere in file. |
| `Alt + Up / Down` | Move line up/down. | Place cursor on line `import React from 'react'`, press `Alt+Up` to move it to line 1. |
| `Alt + Shift + Down` | Duplicate line down. | Duplicate `console.log("Test 1");` to quickly create `console.log("Test 2");`. |
| `Ctrl + /` | Toggle comment/uncomment. | Select 10 lines of code and press `Ctrl+/` to comment them out instantly. |
| `Shift + Alt + F` | Format entire document. | Press `Shift+Alt+F` to clean up messy indentation and formatting in your JS/HTML file. |
