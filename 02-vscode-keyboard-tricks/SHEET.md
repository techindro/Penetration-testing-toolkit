# 💻 Module 02: VS Code Keyboard Shortcuts Master Sheet (30 Shortcuts)

Complete reference for 30 essential VS Code keyboard shortcuts for Windows/Linux categorized by difficulty level (🟢 Easy, 🟡 Medium, 🔴 Hard).

---

## 🟢 Level 1: Easy / Beginner Shortcuts (1 - 10)

| # | Key Combination | Action (What it does) | Practical Usage Example |
| :-: | :--- | :--- | :--- |
| **1** | `Ctrl + P` | Quick Open File by name. | Press `Ctrl+P`, type `app.js` to open file instantly. |
| **2** | `Ctrl + Shift + P` | Command Palette (All VS Code settings). | Press `Ctrl+Shift+P`, type `Format Document`. |
| **3** | `Ctrl + B` | Toggle Side Bar Visibility. | Hide file tree sidebar to maximize code viewing space. |
| **4** | `Ctrl + /` | Toggle Line / Block Comment. | Select lines and press `Ctrl+/` to comment/uncomment. |
| **5** | `Ctrl + S` | Save File. | Save current open document. |
| **6** | `Ctrl + F` | Find in Current File. | Search text inside active document. |
| **7** | `Ctrl + H` | Find and Replace in Current File. | Replace variable names across file. |
| **8** | `Ctrl + ` ` (Backtick) | Toggle Integrated Terminal. | Open or hide terminal panel at bottom. |
| **9** | `Ctrl + Z` | Undo. | Undo last edit action. |
| **10** | `Ctrl + Y` | Redo. | Redo previously undone action. |

## 🟡 Level 2: Medium / Intermediate Shortcuts (11 - 20)

| # | Key Combination | Action (What it does) | Practical Usage Example |
| :-: | :--- | :--- | :--- |
| **11** | `Ctrl + Shift + F` | Search Across Entire Project. | Find all references of `DATABASE_URL` in workspace. |
| **12** | `Ctrl + Shift + H` | Global Find & Replace in Project. | Replace function name across all workspace files. |
| **13** | `Alt + Up / Down` | Move Current Line Up/Down. | Shift line 14 above line 13 without cutting/pasting. |
| **14** | `Shift + Alt + Down` | Duplicate Current Line Down. | Duplicate active code line directly underneath. |
| **15** | `Ctrl + D` | Select Next Matching Word. | Select 5 occurrences of variable `x` to rename all 5. |
| **16** | `Ctrl + G` | Jump to Specific Line Number. | Type `Ctrl+G` then `145` to jump straight to line 145. |
| **17** | `Ctrl + Shift + O` | Jump to Symbol / Function in File. | Type `@handleClick` to jump to function declaration. |
| **18** | `F12` | Go to Definition. | Jump to source code definition of imported class/method. |
| **19** | `Alt + F12` | Peek Definition. | View inline popup preview of function definition. |
| **20** | `Shift + F12` | Find All References. | View list of all files referencing a class or variable. |

## 🔴 Level 3: Hard / Advanced Pro Tricks (21 - 30)

| # | Key Combination | Action (What it does) | Practical Usage Example |
| :-: | :--- | :--- | :--- |
| **21** | `Alt + Click` | Multi-Cursor Freeform Click. | Click on lines 10, 20, 30 to type text on all 3 simultaneously. |
| **22** | `Ctrl + Alt + Down` | Insert Cursor Above/Below. | Add multi-cursor column straight down across 10 lines. |
| **23** | `Ctrl + Shift + L` | Select All Occurrences of Current Word. | Select all 25 instances of `user_id` across file. |
| **24** | `F2` | Rename Symbol Across Project. | Safely rename variable across all files and imports. |
| **25** | `Shift + Alt + F` | Format Document (Prettier/Black). | Instantly re-indent and auto-format entire file. |
| **26** | `Ctrl + K` `Ctrl + S` | Keyboard Shortcuts Settings. | Customize keyboard shortcuts. |
| **27** | `Ctrl + K` `V` | Open Markdown Side Preview. | View live rendered HTML output of active Markdown file. |
| **28** | `Ctrl + \` | Split Editor Window. | View two files side-by-side in split editor view. |
| **29** | `Ctrl + W` | Close Active Editor Tab. | Close current open tab. |
| **30** | `Ctrl + Shift + T` | Reopen Last Closed Tab. | Reopen tab accidentally closed a moment ago. |
