# 💻 Module 02: VS Code Keyboard Shortcuts & Pro Tricks

Essential keyboard shortcuts for fast coding, editing, and debugging in Visual Studio Code.

---

## ⚡ 1. Daily Navigation & Search Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Shift + P` | Open Command Palette (Access any setting or action instantly). |
| `Ctrl + P` | Quick File Open (Type filename to jump directly to any file). |
| `Ctrl + B` | Toggle left sidebar visibility on/off. |
| `Ctrl + ~` (Backtick) | Open / close integrated terminal. |
| `Ctrl + Shift + F` | Search across ALL files in workspace. |
| `Ctrl + G` | Jump directly to line number. |

---

## ✏️ 2. Fast Editing & Multi-Cursor Tricks

| Shortcut | Action |
| :--- | :--- |
| `Alt + Click` | Add multiple cursors at clicked positions. |
| `Ctrl + D` | Select current word, press again to select next matching occurrence. |
| `Alt + Up / Down` | Move current line/selection up or down. |
| `Alt + Shift + Up / Down` | Duplicate current line up or down. |
| `Ctrl + /` | Toggle single line comment/uncomment. |
| `Shift + Alt + F` | Format entire code document nicely. |
