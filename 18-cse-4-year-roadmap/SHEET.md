## 📚 Semester-by-Semester Milestones

### 🟢 Year 1: Coding Foundations & Tools
- **Languages:** C++ / Java / Python.
- **Tools:** Linux CLI, Git, VS Code.
- **Focus:** Build small CLI projects, solve 100+ basic problem-solving questions on LeetCode/GeeksforGeeks.

### 🔵 Year 2: Core CS Subjects & DSA Mastery
- **Subjects:** Operating Systems, DBMS, Computer Networks, Theory of Computation.
- **DSA:** Recursion, Trees, Binary Search, Graphs (BFS/DFS), Dynamic Programming.
- **Focus:** Build CRUD web applications, understand socket programming & database normalization.

### 🟡 Year 3: Domain Specialization & Industry Readiness
- **Track Selection:** Choose Web Dev (MERN/Next.js), App Dev (Flutter/Native), AI/ML (PyTorch/Scikit-learn), or Cyber Security (OWASP/Pentesting).
- **Projects:** Build 2 full-stack, deployed production-level projects.
- **Internships:** Apply for software engineering & security research internships.

### 🔴 Year 4: Capstone Projects & Placement / Higher Studies
- **Major Project:** End-to-end engineered system with CI/CD deployment pipelines, system design documentation, and clean code principles.
- **System Design:** LLD (Object Oriented Design Patterns) & HLD (Distributed Systems, Microservices, Caching).
